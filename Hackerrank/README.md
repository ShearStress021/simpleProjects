# A collection of Hackerank solutions

My solutions to HackerRank programming challenges.

## Running a solution

Use the runtime for the language of the selected solution. For example, to run a CPP solution:

```bash
make run target=solution.cpp
```

HackerRank supplies input through standard input, so the same approach can be used locally with a sample input file.
